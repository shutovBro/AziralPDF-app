# Подача уведомления о ПДн на eGov.kz — пошагово

> Готовый сценарий: что нажать, что вписать. На всё про всё — **15–25 минут**, бесплатно.
>
> ⚠️ Интерфейс eGov меняется. Если найдёшь расхождения — обновим этот гайд.

---

## 0. Нужно ли тебе подавать вообще?

**Да, нужно.** Ты ИП, обрабатываешь данные клиентов (e-mail, IP, имя, платежи) — ты **«собственник базы персональных данных»** по ст. 1 Закона РК № 94-V от 21.05.2013.

Освобождение есть **только** для:
- семейно-личной обработки (это не про тебя);
- журналистской деятельности;
- ПДн без идентификации лица (только обезличенные счётчики).

Срок: уведомление подаётся **до начала обработки**. У тебя сервис уже работает → подай в течение ближайших дней, чтобы прикрыть тыл.

Штраф за неподачу — **ст. 79 КоАП РК**, до **200 МРП** (≈ 740 000 ₸ в 2026 г.) для ИП.

## 1. Что нужно иметь под рукой

| Требование | Где взять |
|---|---|
| **ЭЦП** (электронная цифровая подпись) физлица | у тебя точно есть (ты регистрировал ИП); ключи на NCALayer или мобильное приложение **eGov Mobile** |
| **ИИН** | твой 12-значный |
| **Полный адрес** | как в свидетельстве о регистрации ИП |
| **Учётная запись** на eGov.kz | войти через ЭЦП или eGov Mobile |
| **Описание обработки ПДн** | готов ниже в этом гайде — копипастишь |

Установи **NCALayer** (если ещё не стоит) — это десктоп-приложение для подписи ЭЦП в браузере:
- macOS: https://pki.gov.kz → скачать .dmg → установить → запустить (висит в трее)
- В Chrome/Safari разреши NCALayer обращаться к browser

## 2. Найти услугу на eGov

1. Открой **https://egov.kz** → войди (`Войти` → ЭЦП через NCALayer **или** QR-кодом через eGov Mobile).
2. В поиске вверху вбей: **«персональных данных»**.
3. Ищи услугу с одним из названий (точное название может варьироваться):
   - **«Информирование уполномоченного органа в сфере защиты персональных данных о начале или прекращении обработки персональных данных»**
   - или: **«Регистрация собственника и/или оператора базы, содержащей персональные данные»**
4. Нажми **«Заказать услугу онлайн»**.

Если поиск ничего не даёт — попробуй на **kgd.gov.kz** или прямо на сайте регулятора: **https://www.gov.kz/memleket/entities/ksi** (Комитет по информационной безопасности МЦРИАП).

### Раздел: Сведения о базе персональных данных

| Поле формы | Что вписать |
|---|---|
| **Наименование базы ПДн** | `База пользователей онлайн-сервиса AziralPDF` |

| **Цели обработки** | `Оказание платных и бесплатных услуг по обработке PDF-документов в режиме SaaS; биллинг и взаиморасчёты; обеспечение безопасности сервиса; информационное взаимодействие с пользователями.` |

### Раздел: Перечень обрабатываемых персональных данных

Вставь как есть:

```
1. Адрес электронной почты (логин)
2. Имя, фамилия (если указаны пользователем добровольно)
3. Хеш пароля (bcrypt, без хранения открытого пароля)
4. IP-адрес, User-Agent, временные метки входов и операций
5. Метаданные операций (название операции, размер файла, время обработки)
6. Идентификатор транзакции платёжной системы (без хранения реквизитов карт)
7. Cookie-файлы и localStorage технического характера
```

### Раздел: Способы обработки

| Поле | Значение |
|---|---|
| Способ обработки | **Автоматизированный** (электронные системы) |
| С использованием средств вычислительной техники | **Да** |
| Без использования средств автоматизации (бумажные носители) | **Нет** |

### Раздел: Меры защиты ПДн

Вставь как есть (это всё ты уже сделал):

```
- Передача данных по защищённому каналу HTTPS с TLS 1.3
- Хранение паролей в виде криптографических хешей bcrypt с индивидуальной солью
- Шифрование диска хранилища (LUKS/AES-XTS)
- Двухфакторная аутентификация (TOTP) для администраторов
- Журналирование критичных операций
- Регулярное обновление компонентов с устранением выявленных уязвимостей
- Ограничение доступа к серверу по SSH с использованием ключей
- Резервное копирование с проверкой целостности (SHA-256 манифесты)
- Назначен ответственный за организацию обработки ПДн (собственник ИП)
```

### Раздел: Сроки обработки и хранения

| Категория | Срок | Основание |
|---|---|---|
| Учётная запись | весь срок действия + 1 год | возможные претензии |
| Загруженные файлы | до 24 часов | минимизация (ст. 6 Закона о ПДн) |
| Метаданные операций | 3 года | срок исковой давности (ст. 178 ГК РК) |
| Платёжные транзакции | 5 лет | ст. 193 НК РК |
| Лог-файлы безопасности | 90 дней | реализация законных интересов |

## 4. Подписание ЭЦП и отправка

1. После заполнения — нажми **«Подписать и отправить»**.
2. NCALayer попросит выбрать ключ → выбери **RSA-ключ физлица** (не AUTH, а GOST/RSA для подписи).
3. Введи пароль от ключа.
4. Готово — увидишь номер заявки.
5. На e-mail и в личный кабинет eGov прилетит **уведомление о принятии**.

Срок рассмотрения: услуга **уведомительная** — официального решения не выносится, факта подачи достаточно. По регламенту — до 15 рабочих дней на принятие к учёту.

## 5. Что сделать сразу после подачи

### a) Сохрани доказательство

В личном кабинете eGov → «Мои заказы» → найди заявку → **скачай PDF-квитанцию** с ЭЦП регулятора. Положи в:

```
~/AziralPDF-app/legal/compliance/egov-pdn-notification-<дата>.pdf
```

Это твоё доказательство на случай проверки.

### b) Подпиши внутренний приказ о назначении ответственного

Один лист на ИП-бланке (можно от руки):

```
ПРИКАЗ № 1

г. Астана                                          <дата>

О назначении ответственного за организацию
обработки персональных данных

В соответствии с подпунктом 6) пункта 1 статьи 11
Закона Республики Казахстан "О персональных данных
и их защите" от 21 мая 2013 года № 94-V

ПРИКАЗЫВАЮ:

1. Назначить ответственным за организацию обработки
   персональных данных в ИП "<ФИО>"
   собственника — <ФИО>, ИИН <ИИН>.

2. Утвердить, что обработка ПДн осуществляется
   на условиях Политики конфиденциальности,
   размещённой по адресу
   https://pdf.aziral.com/legal/privacy.

3. Контроль за исполнением настоящего приказа
   оставляю за собой.

Индивидуальный предприниматель        ___________
                                        <ФИО>
```

Подпиши, отсканируй, положи рядом с квитанцией eGov.

### c) Веди журнал обращений субъектов ПДн

Можно в Google Sheets с колонками: дата → имя → e-mail → запрос (доступ/изменение/удаление) → дата ответа → результат. На случай если кто-то попросит удалить данные — у тебя будет лог.

## 6. Подводные камни

| Грабли | Как обойти |
|---|---|
| Услуга «Регистрация в Реестре» с 2022 г. **отменена** — ищи именно «уведомление», не «регистрацию» | если eGov предлагает архивную услугу — это не та |
| NCALayer **не запускается** в современных Safari/Chrome из-за CSP | используй Firefox или скачай **eGov Browser** (отдельный chromium от eGov с предустановленным NCALayer) |
| Форма требует БИН вместо ИИН | у ИП **нет БИН** — оставь поле пустым или впиши свой ИИН (он принимается) |
| Просит **прикрепить документ** «Политика обработки ПДн» | прикрепи распечатку `~/AziralPDF-app/legal/filled/privacy.kz.md` (или скачай с https://pdf.aziral.com/legal/privacy → Print → Save as PDF) |
| После подачи **e-mail не приходит** | загляни в спам; альтернатива — личный кабинет eGov → «История» |

## 7. Если что-то пошло не так

- **Горячая линия eGov:** `1414` (бесплатно по РК)
- **Комитет по информационной безопасности МЦРИАП РК:**
  - сайт: https://www.gov.kz/memleket/entities/ksi
  - приёмная: тел. + e-mail указаны на сайте
- **Чат поддержки eGov:** правый нижний угол на egov.kz

Звонок на 1414 решает 80% проблем за 5 минут — оператор может подсказать конкретный раздел / название услуги.
