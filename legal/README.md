# Юридические документы AziralPDF (право Республики Казахстан)

Комплект документов для запуска платного SaaS-сервиса на домене **aziral.com** под ИП в Казахстане.

> Документы подготовлены на основе типовых SaaS-шаблонов с учётом:
> - **ГК РК** (публичная оферта — ст. 395, 396; ответственность — ст. 9; исковая давность — ст. 178);
> - **Закона РК «О персональных данных и их защите» № 94-V от 21.05.2013**;
> - **Закона РК «Об электронном документе и ЭЦП»**;
> - **Налогового кодекса РК** (срок хранения первичных документов — 5 лет, ст. 193).
>
> Положения максимально защищают вас как оператора в рамках, допускаемых законом РК.

## Заполнение плейсхолдеров

### Вариант 1 — интерактивно (рекомендуется)

```bash

```

Скрипт спросит ваши данные, создаст папку `filled/` с готовыми документами.

## Что выбрать в качестве платёжного провайдера (рекомендации)

| Провайдер | Когда выбирать | Комиссия | Минусы |
|---|---|---|---|
| **Kaspi Pay** | если основная аудитория — РК, физлица | ≈ 1.5–2% | требует юр.лицо/ИП, KZT only, нет авторекуррента «из коробки» |
| **Halyk Bank — Onlinebank Acquiring** | классический эквайринг для ИП | ≈ 2.5% | сложнее API, документация скудная |
| **CloudPayments Kazakhstan** | если нужен **рекуррент** (подписки автосписанием) | 2.5–3% | требует переписки на подключение |
| **PayBox.kz** | универсальный — карты + Kaspi QR + Apple Pay | 2.5–3.5% | средний API |
| **Stripe** | если планируете **международных** клиентов в USD/EUR | 2.9% + $0.30 | официально не принимает ИП РК как мерчанта — нужен Stripe Atlas (US LLC); НЕ рекомендую на старте |

**Мой совет на старте:**
1. Если работаете преимущественно с физлицами РК — **Kaspi Pay** (быстро подключить, доверие пользователей, низкая комиссия).
2. Если нужна автоматическая ежемесячная подписка — **CloudPayments KZ**.

После выбора замените `Kaspi Pay` на ваш провайдер во всех документах одной командой:

```bash
cd ~/AziralPDF-app/legal/filled
sed -i 's|Kaspi Pay|CloudPayments Kazakhstan|g' *.md
```

## Что выбрать в качестве хостинг-провайдера

Текущий деплой работает на вашем сервере. Если это VPS в **РК (PS.kz, Kazteleport, QazCloud)** — данные внутри страны, никаких проблем с трансграничной передачей по ст. 16 Закона о ПДн.

Если хостинг **за пределами РК** (например, в РФ, ЕС, США) — это допустимо, но Политика конфиденциальности уже корректно описывает трансграничную передачу. Просто замените `PS Internet Company (ps.kz)` на реального провайдера.

## Публикация документов

Сервис уже сконфигурирован — нужно только разместить готовые HTML/MD по URL:

### Самый быстрый способ — Cloudflare Pages

1. Создайте репозиторий `aziral-legal` на GitHub
2. Залейте туда `filled/*.md` + минимальную обёртку
3. Cloudflare Pages → подключите репозиторий, билд через `mkdocs` или просто статика
4. Привяжите домен `aziral.com` (или поддомен `legal.aziral.com`)
5. Делайте 301-редиректы:
   - `/offer` → `/offer.html`
   - `/terms` → `/terms.html`
   - `/privacy` → `/privacy.html`
   - `/cookies` → `/cookies.html`

Время на запуск: 15–30 минут.

### Альтернатива — Notion / Tilda / любой конструктор

Скопировать содержимое .md в страницу и опубликовать. Дёшево и быстро.

## Регулирование персональных данных в РК — что ОБЯЗАТЕЛЬНО сделать ИП

### 1. Уведомление уполномоченного органа

В соответствии со **ст. 25 Закона о ПДн** оператор обязан уведомить Комитет по информационной безопасности МЦРИАП РК о намерении обрабатывать ПДн **до начала обработки**.

**Как:** через **eGov.kz** → услуга «Уведомление о сборе и обработке персональных данных».
**Срок подачи:** до запуска сервиса в публичном доступе.
**Госпошлина:** отсутствует.
**Срок рассмотрения:** уведомительный порядок — реакция не требуется, достаточно факта подачи.

### 2. Назначить ответственного за обработку ПДн

ИП может назначить ответственным **самого себя** — приказом «о назначении ответственного за обработку и защиту персональных данных» на собственное имя. Один лист, остаётся у вас в файле.

### 3. Документы внутреннего пользования

Не публикуются, но должны быть на случай проверки:

- **Политика обработки ПДн** (внутренняя, более развёрнутая чем публичная privacy);
- **Перечень обрабатываемых ПДн**;
- **Перечень мест хранения и обработки**;
- **Журнал учёта обращений субъектов ПДн** (можно вести в Google Sheets).

Шаблоны есть на портале **eGov.kz** в разделе «Защита персональных данных».

### 4. Регистрация в Реестре операторов ПДн (старая модель)

С 2022 года **отменена** — отдельной регистрации в реестре больше не требуется. Достаточно уведомления (см. п. 1).

## Налоги (краткая шпаргалка для ИП РК)

Не входит в комплект документов, но критично для финансовой модели:

| Режим | Когда | Налог |
|---|---|---|
| **Упрощённая декларация (упрощёнка)** | оборот до **24 038 МРП в год** (≈ 88 млн ₸ в 2026 г.) | **3% от дохода** + соц. отчисления |
| **СНР на основе патента** | для очень мелких ИП без наёмных | фиксированная сумма |
| **Общеустановленный режим** | если упрощёнка не подходит | 10% ИПН + НДС (если оборот выше порога) |

**Регистрация плательщика НДС** обязательна при обороте свыше **20 000 МРП за год** (≈ 73 млн ₸). До этого порога — не регистрируйтесь.

Для SaaS на старте: **упрощёнка** — оптимальна.
